# Study Notes

- `papers/` — one file per paper. Filename: `{arxiv-id-or-slug}.md`.
- `books/` — one file per chapter. Filename: `{book-slug}-ch{N}.md`.
- `private/` — gitignored. Half-formed thoughts, interview notes, anything I don't want public yet.

Every note file starts with a frontmatter block:

```yaml
---
title:
source:
tags: []
status: reading | drafted | done
---
```

This is Obsidian-compatible and greppable.
