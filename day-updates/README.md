# Day Updates

One file per workday. Use `_template.md` as the starting point.

**Naming:** `YYYY-MM-DD.md` (ISO 8601 for lexicographic sort).

Create a new day file by running `../scripts/new-day.sh` from the repo root.

**Recovery rule:** if I miss 3+ days in a row, the next update starts with a one-paragraph honest catch-up rather than backfilling empty files.
