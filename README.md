## How this repo works

- The plan lives in `PLAN.md` and is versioned. When it changes, the change goes in `CHANGELOG.md` with reasoning.
- Every workday I write one file in `day-updates/YYYY-MM-DD.md` describing what I did.
- Bi-weekly, I publish a longer post in `blog/`.
- Study notes for papers and books live in `notes/`. Some are private (gitignored).
- Each project (nanoGPT, kvstore-server, inference-server-rs, etc.) lives in its own repo; this one links to them under `projects/`.

## Obsidian setup

This repo doubles as an Obsidian vault. Recommended plugins:

- **Daily Notes** (core) — point at `day-updates/`, template `_template.md`.
- **Templater** — for auto-filling day number and phase.
- **Tasks** — checkbox tracking.
- **Dataview** — dashboards.
- **Obsidian Git** — auto-commit and push on a schedule.

Do not commit `.obsidian/plugins/*/data.json` or workspace files — they are gitignored.
